# Skills

Agent skills for Claude Code, Codex, and other tools that read `SKILL.md` folders.

| Skill | What it does |
| --- | --- |
| [direct-optimize](direct-optimize/SKILL.md) | Finds and fixes hot-path waste: needless sequential awaits, over-fetching queries, repeated parsing, and hot keys in large JSON columns. |

## Install

Copy or symlink a skill folder into your agent's skills directory:

- Claude Code: `~/.claude/skills/<name>/`
- Codex: `~/.agents/skills/<name>/`
